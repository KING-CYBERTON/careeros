# Test plan — P0-C01 CI workflow

Level: pipeline verification (manual, evidence in PR).

| #   | Case                                        | Expected                                                   |
| --- | ------------------------------------------- | ---------------------------------------------------------- |
| 1   | Open the task PR                            | `careeros-ci` runs jobs `static`, `unit`, `e2e`; all green |
| 2   | Throwaway PR with a lint error (not merged) | `static` fails                                             |
| 3   | Throwaway PR with a failing unit assertion  | `unit` fails                                               |
| 4   | Push a second commit to an open PR quickly  | first run cancelled                                        |
| 5   | Logs show `--filter=!mobile`                | yes, mobile not typechecked/tested                         |
| 6   | Upstream workflows                          | disabled; no runs on the PR                                |
| 7   | Durations recorded in PR description        | static, unit, e2e minutes (input for E3)                   |
| 8   | Push to `develop` after merge               | workflow runs on push                                      |
