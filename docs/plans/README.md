# docs/plans — phase plans and task specs (Opus only)

- File name: `<ID>-<short-name>.md`, IDs `P<phase>-T<nn>` (Build), `P<phase>-Q<nn>` (QA), `P<phase>-C<nn>` (CI/CD, kept in `cicd/`).
- Every spec has: Status (Draft / **Approved** / Done), Thread, Depends on, Goal, Scope (in/out), Files, Steps, Acceptance criteria, Risks, Test plan link.
- Sonnet only starts specs marked **Approved**. Anything a spec leaves open goes to `../questions.md`.
