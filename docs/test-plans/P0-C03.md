# Test plan — P0-C03 Staging

| #   | Case                                           | Expected                                                                                               |
| --- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 1   | Docs-only merge to `develop`                   | staging auto-deploys; `/api/health` shows new SHA within 15 min of merge                               |
| 2   | HTTPS                                          | valid Cloudflare certificate for staging host; HTTP redirects to HTTPS (Cloudflare "Always Use HTTPS") |
| 3   | Ports                                          | `docker compose ps` shows no published host ports; no inbound port forward added for staging           |
| 4   | Smoke                                          | `smoke.mjs` passes against staging                                                                     |
| 5   | Broken deploy (dispatch with non-existent tag) | run fails, rollback runs, previous SHA still served                                                    |
| 6   | Manual rollback                                | `rollback.sh` restores previous tag in < 3 min                                                         |
| 7   | Data survives redeploy                         | create a resume in staging, redeploy same tag, resume still there                                      |
| 8   | Secrets                                        | `git grep` for secret-looking values in `infra/` → none; workflow logs show no secret values           |
| 9   | Manual UI check (Opus)                         | sign up, create resume, export PDF on staging                                                          |
